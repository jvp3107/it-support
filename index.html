IT Self Diagnostics & KB

Standard operating procedures and self-resolution guides for common infrastructure issues.

  1. Navigate to the official portal: passwordreset.microsoftonline.com.
  2. Enter your corporate email address.
  3. Complete the verification CAPTCHA and select "Next".
  4. Authenticate via your registered MFA method (Authenticator App or SMS).
  5. Create a new password (Min 12 chars, alphanumeric + special).

If external VPN tunneling fails, perform these checks before escalating:

  • Verify stable local internet connection (ping 8.8.8.8).
  • Open the Sophos Connect / Cisco AnyConnect client console.
  • Confirm the Gateway IP matches your onboarding documentation.
  • Approve the MFA push notification on your mobile device immediately upon connection.

Execute these steps to resolve 80% of endpoint anomalies:

  • System Refresh: Perform a full OS Restart (Do not use "Shut Down").
  • Network Handshake: Physically reseat Ethernet cables or cycle Wi-Fi adapters.
  • Browser Isolation: Test failing web apps in Incognito/InPrivate mode.
  • Hardware Cycle: Disconnect power from failing peripherals for 10 seconds.
  • Pending Updates: Check Windows Settings > Update & Security.

For sluggish performance or low disk warnings, run the pre-configured optimization batch file:

  1. Locate the Spread Daily Maintenance shortcut on your Desktop.
  2. Right-click the icon and select "Run as Administrator".
  3. Allow the console to purge temp files, flush DNS caches, and run TRIM/Defrag.
  4. Restart your endpoint once the console automatically closes.

If emails are stuck in Outbox or not updating:

  1. Close Microsoft Outlook completely.
  2. Press Windows Key + R to open the Run dialog.
  3. Type outlook.exe /cleanprofile and press Enter.
  4. If prompted, select your default profile.
  5. Allow 5-10 minutes for the local .OST file to rebuild and sync with the Exchange server.

To clear a stuck print queue or unresponsive network printer:

  1. Open the Start Menu, type CMD, right-click and select Run as Administrator.
  2. Type net stop spooler and press Enter.
  3. Open File Explorer and navigate to C:\Windows\System32\spool\PRINTERS.
  4. Delete all files inside this folder (Do not delete the folder itself).
  5. Return to the command prompt, type net start spooler, and press Enter.

If your endpoint is locked and requesting a BitLocker recovery key:

  1. On a secondary device (e.g., mobile phone), navigate to myaccount.microsoft.com.
  2. Sign in using your corporate email and password.
  3. Click on the "Devices" section.
  4. Locate your locked computer name in the list and click "Get BitLocker Keys".
  5. Enter the 48-digit numerical password into the locked computer.

To resolve internal web portal rendering or login loop errors:

  1. Open your browser and press Ctrl + Shift + Delete.
  2. A "Clear browsing data" window will appear.
  3. Change the Time Range dropdown to "All time".
  4. Ensure "Cookies and other site data" and "Cached images and files" are checked.
  5. Click the "Clear data" button and restart the browser.
