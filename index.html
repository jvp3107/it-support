Self-Service Knowledge Base

Find quick solutions to common IT issues regarding Microsoft 365, Network Security, and active directory systems.

  1. Navigate to the Microsoft Online Password Reset portal: passwordreset.microsoftonline.com.
  2. Enter your corporate Spread Technical email address.
  3. Complete the CAPTCHA and select "Next".
  4. Choose your verification method (Authenticator App, SMS, or Alternate Email).
  5. Enter the code and create a new strong password.

Note: Password must be at least 12 characters, include a number and special character. It may take up to 15 minutes to sync with local Active Directory.

If you are unable to connect to the corporate VPN from outside the UAE office, verify the following:

  • Ensure you are connected to a stable internet connection.
  • Open the Sophos Connect / Cisco AnyConnect client.
  • Verify the gateway address is correct as per your onboarding documentation.
  • If authentication fails, ensure your Multi-Factor Authentication (MFA) token is approved promptly.
  • If it says "Certificate Validation Failure", please raise a ticket for IT to push the latest certificate via Group Policy.
