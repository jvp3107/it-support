IT Service Catalog & KB

Standard operating procedures and self-resolution guides for common infrastructure issues.

  1. Navigate to the official portal: passwordreset.microsoftonline.com.
  2. Enter your corporate Spread Technical email address.
  3. Complete the verification CAPTCHA and select "Next".
  4. Authenticate via your registered MFA method (Authenticator App or SMS).
  5. Create a new password (Min 12 chars, alphanumeric + special).

Note: It may take up to 15 minutes for the new credentials to sync with local Active Directory endpoints.

If external VPN tunneling fails, perform these checks before escalating:

  • Verify stable local internet connection (ping 8.8.8.8).
  • Open the Sophos Connect / Cisco AnyConnect client console.
  • Confirm the Gateway IP matches your onboarding documentation.
  • Approve the MFA push notification on your mobile device immediately upon connection.
  • If prompted with "Certificate Validation Failure", submit a ticket for Group Policy redeployment.

Execute these steps to resolve 80% of endpoint anomalies:

  • System Refresh: Perform a full OS Restart (Do not use "Shut Down", select "Restart" to flush the kernel).
  • Network Handshake: Physically reseat Ethernet cables or cycle Wi-Fi adapters.
  • Browser Isolation: Test failing web apps in Incognito/InPrivate mode to rule out corrupt cache data.
  • Hardware Cycle: Disconnect power from failing peripherals (docks, monitors) for 10 seconds to drain capacitors.
  • Pending Updates: Go to Windows Start > Settings > Update & Security and check if your PC is pending a critical restart for driver updates.

For sluggish performance or low disk warnings, run the pre-configured optimization batch file:

  1. Locate the Spread Daily Maintenance shortcut on your Desktop.
  2. Right-click the icon and select "Run as Administrator".
  3. Allow the console to purge temp files, flush DNS caches, and run TRIM/Defrag operations.
  4. Restart your endpoint once the console automatically closes.

Note: Execution takes 2-5 minutes. Do not interrupt the terminal process.

To add a network printer to your Windows endpoint, follow these standard steps:

  1. Press the Windows Key and type Printers & Scanners, then hit Enter.
  2. Click Add a printer or scanner.
  3. Wait for the system to scan the network. If your printer appears, select it and click Add device.
  4. If it does not appear, click "The printer that I want isn't listed".
  5. Select "Find a printer in the directory, based on location or feature" to search the Active Directory, or choose "Add a printer using a TCP/IP address" if you know the printer's IP.

Note: If prompted for administrative credentials to install print drivers, please submit a service request.

If you have been granted access to a department shared mailbox (e.g., info@ or support@), here is how to view it:

  • Outlook Desktop App: Restart Outlook. Automapping usually adds the shared mailbox to your left navigation pane automatically within 30-60 minutes of access being granted.
  • Outlook on the Web (OWA): Right-click on "Folders" in the left pane, select "Add shared folder", type the name or email address of the shared mailbox, and click Add.
  • Send As: To send an email from the shared mailbox, open a New Email, click the "From" dropdown, select "Other Email Address", and type the shared mailbox name.

If files are failing to sync to your corporate SharePoint Document Libraries:

  • Look for the blue cloud icon in your Windows system tray. If there is a red 'X', click it to view sync conflicts (often caused by invalid characters in filenames like * : < > ? / \ |).
  • Ensure the file path does not exceed the Windows 256-character limit.
  • If the OneDrive icon is gray with a line through it, you are signed out. Click it to re-authenticate with your M365 credentials.
  • To perform a hard reset on the sync engine: Press Windows Key + R, type %localappdata%\Microsoft\OneDrive\onedrive.exe /reset, and press Enter.

If your endpoint restarts and asks for a BitLocker Recovery Key (a blue screen with a white input field):

  1. Do not attempt to guess the key. This is a security measure triggered by hardware changes, BIOS updates, or docking station swaps.
  2. From a mobile device or secondary computer, log in to your Microsoft 365 account at myaccount.microsoft.com.
  3. Navigate to Devices, find your computer name, and select "View BitLocker Keys".
  4. Enter the 48-digit numerical key into your locked endpoint.

If you cannot access your account, call the IT NOC directly. Do NOT format the drive.
